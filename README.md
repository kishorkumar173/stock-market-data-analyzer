# 📈 Stock Market Data Analyzer

A professional full-stack fintech dashboard built using **FastAPI**, **Next.js**, **TypeScript**, and **Python** for analyzing real-time stock market data, technical indicators, and financial trends.

---

# 🚀 Project Overview

The **Stock Market Data Analyzer** is a real-time financial analytics platform that allows users to:

- Analyze stock performance
- Visualize technical indicators
- Track moving averages
- Monitor RSI & MACD signals
- View candlestick charts
- Analyze volatility and trends
- Simulate portfolio analytics
- Explore AI-based buy/sell signals

This project demonstrates:
- Financial data analysis
- API development
- Full-stack web development
- Data visualization
- FinTech dashboard design
- Real-time analytics systems

---

Investors and analysts need tools to:

     ⚙️ Installation
1️⃣ Clone Repository
git clone https://github.com/yourusername/stock-market-data-analyzer.git
2️⃣ Backend Setup
cd backend

Create virtual environment:

python -m venv venv

Activate virtual environment:

Windows
venv\Scripts\activate

Install dependencies:

pip install fastapi uvicorn pandas numpy yfinance

Run backend server:

python -m uvicorn app.main:app --reload

Backend URL:

http://127.0.0.1:8000
3️⃣ Frontend Setup
cd frontend

Install dependencies:

npm install

Install charts:

npm install react-apexcharts apexcharts

Run frontend:

npm run dev

Frontend URL:

http://localhost:3000
